Install guide

Har device par ek minute mein.

Windows / laptop

  1. Chrome ya Edge mein AK47 kholen
  2. Address bar ke install icon, ya app ke "Install" button par click karein
  3. Desktop aur Start menu mein AK47 aa jayega

Android

  1. Chrome mein app kholen
  2. "Install" ya menu → "Add to Home screen" dabayen
  3. Home screen par AK47 ka icon aa jayega

iPhone

  1. Safari mein app kholen
  2. Share button → "Add to Home Screen"
  3. Icon se kholen, full screen chalega

Kya internet zaroori hai?

Haan. AK47 online chalta hai taake har device par ek hi data rahe. Counter par backup internet (4G device) rakhna behtar hai.

Mera data kahan rehta hai?
